# 🚗 نظام الكشف التلقائي عن أضرار السيارات

يعتمد هذا المشروع على نموذج ذكاء اصطناعي للرؤية الحاسوبية (**YOLO11m**) يقوم بفحص صور هياكل السيارات والتعرف التلقائي على أماكن الحوادث والتلفيات بدقة عالية. 
يقوم الموديل بتحديد مكان الضرر عبر رسم مربعات تحديد (**Bounding Boxes**) وتوضيح نوع التلف ونسبة التأكد لكل صدمة أو خدش، مما يساعد في أتمتة عمليات تقييم وتقدير تكاليف الحوادث بدقة وسرعة.

---

### 🔍 التصنيفات الـ 8 التي يكتشفها الموديل:

| # | اسم الكلاس في الموديل | المعنى بالعربي | أمثلة عملية على العربية |
|:-:|:----------------------|:---------------|:------------------------|
| **0** | `no_damage` | **سيارة سليمة تماماً** | لما العربية تكون فابريكا ومفيهاش أي خبطات أو خدوش. |
| **1** | `lost parts` | **أجزاء مفقودة / طايرة** | جزء طار من العربية بسبب الحادثة (مراية مخلوعة، إكصدام واقع، شبكة أمامية طايرة). |
| **2** | `torn` | **تمزق / شق في الصاج** | الصاج أو الرفرف اتقطع أو اتشرخ نتيجة احتكاك قوي. |
| **3** | `dent` | **صدمة / انبعاج (خبطة)** | صاج مضغوط لجوة ومطبق (خبطة في الباب، الكبوت، أو الرفرف). |
| **4** | `paint scratch` | **خدوش في الدهان** | تجريح وحكّ في بوية السيارة الخارجية. |
| **5** | `hole` | **ثقب / خُرم** | كسر غائر أو فتحة نافذة في الإكصدام أو الفايبر. |
| **6** | `broken glass` | **زجاج مكسور** | كسر أو شروخ في الزجاج الأمامي أو الخلفي أو زجاج الأبواب. |
| **7** | `broken lamp` | **فوانيس / كشافات مكسورة** | كسر أو شرخ في الفوانيس الأمامية (Headlights) أو الخلفية (Taillights). |
